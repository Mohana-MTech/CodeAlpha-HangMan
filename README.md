# CodeAlpha-HangMan

## 📖 Project Overview
- Internship Task 1 under CodeAlpha.
- Classic Hangman game implemented in Python.
- Random word selection with limited attempts.
- Demonstrates loops, conditionals, and string handling.

##  Execution Guide
I used **Visual Studio Code** to run this project:
1. Saved the file as `HangMan.py`.
2. Opened the integrated terminal (`View → Terminal`).
3. Executed the program with:
   python Hangman.py
